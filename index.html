Variables and Data Types

Variables store data that can be used and manipulated throughout your program.

Python has several built-in data types:

  • Strings: Text enclosed in quotes ("Hello" or 'Hello')
  • Integers: Whole numbers without a decimal point
  • Floats: Numbers with a decimal point
  • Booleans: True or False values
  • Lists, Tuples, Dictionaries: Collections of values (covered later)

Control Flow

Conditional Statements

Conditional statements help your program make decisions.

Code Editor
Output

Conditional statements use the keywords if, elif (short for "else if"), and else. Python uses indentation to define code blocks, so be careful with your spacing!

Loops

Loops allow you to repeat code multiple times.

Code Editor
Output

Python offers two main types of loops:

  • For loops: Iterate over sequences (like lists, strings, or ranges)
  • While loops: Continue until a condition becomes False

Special statements:

  • break: Exit the loop immediately
  • continue: Skip the rest of the current iteration and move to the next one

Data Structures

Lists

Lists are ordered, mutable collections that can store different types of data.

Code Editor
Output

Lists are one of Python's most versatile data structures. They can:

  • Store multiple items in a single variable
  • Allow duplicate values
  • Be modified after creation (added to, removed from, reordered, etc.)
  • Store items of different data types

Dictionaries

Dictionaries store data as key-value pairs, providing efficient lookups.

Code Editor
Output

Dictionaries are useful when you need to:

  • Associate values with specific keys (like a real-world dictionary)
  • Look up values quickly without knowing their position
  • Represent real-world objects with attributes

Dictionary keys must be immutable (strings, numbers, tuples, not lists).

Functions

Defining and Using Functions

Functions are reusable blocks of code that perform specific tasks.

Code Editor
Output

Functions help you:

  • Break your code into manageable, reusable parts
  • Avoid repeating code
  • Make your program more organized and easier to understand

Python functions can:

  • Accept parameters (arguments)
  • Have default parameter values
  • Return results
  • Accept variable numbers of arguments with *args and **kwargs

Lambda Functions

Lambda functions are small, anonymous functions defined with the lambda keyword.

Code Editor
Output

Lambda functions are useful when you need a small function for a short period of time, particularly as arguments to higher-order functions like map(), filter(), and sorted().

Syntax: lambda arguments: expression

Limitations:

  • Can only contain a single expression
  • Cannot contain statements or annotations
  • Limited to simple operations
